# Домашня бібліотека
Статичний застосунок українською. Відкрийте через HTTP; npm і збірка не потрібні.

- dist/app.js: UI та керування колекцією.
- dist/storage.js: транзакційне IndexedDB, перевірка резервних копій.
- dist/metadata.js: незалежний адаптер Open Library.
- dist/data.js: чітко відокремлений демоальбом і обмежений каталог підтверджених циклів.

Особисті дані та обкладинки зберігаються лише в браузері, без синхронізації між пристроями. JSON-експорт містить усю колекцію й обкладинки JPEG у data URL. Відновлення замінює колекцію після підтвердження; дію можна скасувати.

Open Library не потребує ключа; запити з браузера залежать від доступності API та CORS. Метадані не вважаються точним українським виданням. Дані циклів обмежені основною трилогією «Перший закон» і трьома самостійними романами світу; джерело — офіційний сайт автора. Для невідомих книг показується недостатність підтверджених даних. Каталог не є універсальним розпізнавачем циклів.

Штатний Sites starter, source helper і cua_repl.js відсутні у наданому середовищі. Використано buildless статичний формат Sites. Перевірка у справжньому браузері та мобільному viewport не виконана.

## Автоматична публікація на GitHub Pages
Workflow `.github/workflows/pages.yml` публікує вміст `dist/` після кожного push у `main`. Додаткові ключі не потрібні: використовується тимчасовий GITHUB_TOKEN.

Одноразово відкрийте Settings → Pages → Build and deployment → Source → GitHub Actions. Після цього запустіть Actions → Publish home library → Run workflow або надішліть новий commit у main.

Адреса Pages: https://anastasiia1001.github.io/home-library/ . Дані з попередньої адреси Sites не переносяться автоматично: експортуйте бібліотеку на старому сайті та відновіть копію на новому.

## Застосунок для MacBook
Збірки для Apple Silicon (arm64, M1 і новіші) та Intel (x64) створює workflow **Build macOS application** після змін коду в main. Готові DMG та ZIP доступні в артефакті Home-Library-macOS відповідного запуску Actions.

Встановлення: відкрийте DMG, перенесіть «Домашня бібліотека» у Applications. Збірка має локальний ad-hoc підпис, але не має сертифіката Developer ID й нотаризації Apple; якщо macOS блокує перше відкриття, скористайтесь System Settings → Privacy & Security → Open Anyway лише для завантаженої тут збірки. Не вимикайте Gatekeeper.

Потрібна macOS 12 або новіша. Для локальної розробки: `npm ci`, потім `npm run desktop`. Для створення інсталяторів на Mac: `npm run build:mac`.

Книги й обкладинки зберігаються в профілі застосунку (Electron userData, IndexedDB), незалежно від браузерної версії. Для перенесення експортуйте JSON на сайті та відновіть його в застосунку. Звичайне оновлення .app зберігає профіль. Без інтернету працює колекція, редагування, пошук у власних книгах і резервні копії; зовнішні метадані потребують мережі.


### Якщо macOS пише «Програму пошкоджено»
Починаючи з 0.1.1 обидві архітектури мають ad-hoc підпис. CI перевіряє його через `codesign --verify --deep --strict` і запускає готовий arm64 застосунок з перевіркою UI та IndexedDB. Це не замінює Developer ID й нотаризацію: Gatekeeper може все одно блокувати завантаження.

Після встановлення саме цієї збірки з цього репозиторію та перенесення у Applications, якщо «Open Anyway» недоступне, можна прибрати карантин лише з цього застосунку в Terminal:

```sh
xattr -dr com.apple.quarantine "/Applications/Домашня бібліотека.app"
```

Це дозволяє запуск неперевіреної Apple збірки. Виконуйте лише для файлу, якому довіряєте; глобальне вимкнення Gatekeeper не потрібне. Якщо помилка залишається, перевірте підпис командою `codesign --verify --deep --strict --verbose=2 "/Applications/Домашня бібліотека.app"`.
